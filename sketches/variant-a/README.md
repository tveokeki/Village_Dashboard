# Variant A: Separate Sidebar Menus (เมนูแยกออกจากกันในแถบเมนูข้าง)

## การออกแบบ UX/UI
ในการออกแบบนี้ สารบัญหรือเมนูแถบข้างของเดสก์ท็อปและปุ่มนำทางหลักจะแยกหน้าที่กันอย่างเด็ดขาด:
1. **รายรับค่าส่วนกลาง (Common Fee Revenue)**
   - มุ่งเน้นไปที่การติดตามสถานะการจ่ายเงินค่าส่วนกลางของสมาชิกในแต่ละหลังคาเรือน (ประวัติการค้างชำระ, รอบบิลรายเดือน/รายปี)
   - มีฟังก์ชันสำหรับการออกรอบบิล (Batch Billing) สำหรับทุกบ้านเลขที่พร้อมกันในแต่ละเดือน
2. **รายรับอื่น ๆ (Other Revenue)**
   - มุ่งเน้นไปที่การจัดเก็บรายรับที่ไม่ได้เชื่อมโยงกับบิลค่าส่วนกลาง (เช่น ดอกเบี้ยธนาคารรับ, เงินประกันความเสียหายงานก่อสร้าง, ค่าปรับ, เงินบริจาค)
   - มีฟังก์ชันอำนวยความสะดวกในการกรอกรายรับทั่วไป ซึ่งไม่มีความผูกมัดว่าต้องเลือกหลังคาเรือน (สมาชิกสามารถเป็นค่าว่างหรือ NULL ได้)

## ข้อดีของ Variant A
- **แยกหน้าที่กันอย่างชัดเจน (Separation of Concerns):** ผู้ใช้งาน (เช่น ฝ่ายบัญชี หรือคณะกรรมการ) ไม่สับสนระหว่างบิลค่าส่วนกลางรายเดือนที่ต้องออกสม่ำเสมอ กับรายรับเบ็ดเตล็ดที่เกิดขึ้นเป็นครั้งคราว
- **ลดการรับข้อมูลที่ไม่จำเป็น:** ในหน้ารายรับอื่น ๆ จะไม่มีช่องกรอกที่ดินหรือการค้นหารอบบิลของบ้านเลขที่ให้รกรุงรัง หน้าจอจึงดูคลีนและเข้าใจง่าย
- **ควบคุม KPI ได้ดีกว่า:** การแสดงผลสรุปยอดค้างชำระของค่าส่วนกลางแยกจากรายรับอื่น ทำให้ประเมินกระแสเงินสดหมุนเวียนหลักได้แม่นยำ

## ข้อจำกัดของ Variant A
- **กินพื้นที่เมนู (Sidebar Bloat):** เพิ่มจำนวนเมนูใน Sidebar อีก 1 รายการ หากในอนาคตมีเมนูการเงินอื่น ๆ เพิ่มขึ้นอีกจะทำให้เมนูดูล้นเกินไป
- **เพิ่มจำนวนคลิกในการเข้าถึงภาพรวม:** หากผู้ใช้ต้องการทราบยอด "รายรับรวมทั้งหมดของหมู่บ้าน" ในวันนั้น ๆ จะต้องคลิกสลับหน้าไปมาถึง 2 ครั้งเพื่อนำยอดมาบวกกันเอง

## การแก้ไขปัญหาในส่วนของ Database
- ในตาราง `slip_processing.payments` ฟิลด์ `member_id` ถูกตั้งค่าเป็น `NOT NULL` ในสกีมาเดิม
- **ทางเลือกที่เลือกใช้ในสเก็ตช์นี้:** ปลดล็อกโดยการเปลี่ยนโครงสร้างฟิลด์ `member_id` ให้เป็น `NULLable` เพื่อรองรับดอกเบี้ยเงินฝากธนาคาร ซึ่งไม่ได้มาจากสมาชิกคนใดเลย และมีค่า `maintenance_fee_id` เป็น `NULL`
- ดึงข้อมูลด้วย SQL `SELECT` ที่ไม่ได้ทำ `INNER JOIN` กับ `maintenance_fees` หรือ `members` แต่ใช้ `LEFT JOIN` เพื่อให้ยอดที่ไม่มีบิลค่าส่วนกลางปรากฏขึ้นมาได้ครบถ้วน
